- Decanter now looks at what each game was made with, such as Unity or Godot, before it starts the game, and picks the setup that suits it. The game's page shows what it found.
- A new Display option opens a game full screen or in a window, for games made with Unity, Godot or Unreal Engine. It replaces Run inside a window and Launch options.
- Double-click a game, or select it and press Return, to play it. Press Delete to remove it from the library.
- Search Games, at the top of the list, finds a game by name.
- Rename a game from the Game menu or by right-clicking it.
- If a game's folder has moved, its page says so straight away. Click Locate… to find it.
- The folder button next to Play shows the game in Finder.
- New games take the name the game gives itself, where it has one.
- The Help menu opens Decanter's guide, or starts a problem report with your Decanter and macOS versions filled in.
- When Decanter switches to another setup, the log keeps the attempt that failed, and Cancel works while it switches.
- If a game fails with every setup, it goes back to the one it started on.
- Stopping a game no longer closes another game whose file has the same name.
- Resetting a Windows environment in Settings no longer freezes the window.
- Decanter won't install an update that isn't newer than the copy you have.
